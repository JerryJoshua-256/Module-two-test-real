# Module 2 — Understanding the Urban Environment Quiz

A static Vercel-ready quiz based on the uploaded Module 2 presentation.

- Welcome screen: **Welcome, Maryam**
- 20 applied multiple-choice questions
- Instant explanations, progress, final score, answer review and retry
- No email service, API key, database, backend or external service

## Run locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Extract this ZIP.
2. Import the project folder/repository in Vercel.
3. Use the project root as the output directory. No build command is needed.
4. Deploy the static site.
